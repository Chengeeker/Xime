# Xime

An Android keyboard built with Kotlin, Jetpack Compose, and Material 3.

- Pinyin, Wubi, and customizable input schemes.
- Adjustable layouts, gestures, clipboard history, and haptic feedback.
- Themes, dynamic colors, plugins, and WebDAV backup.

Android 9.0+ · ARM64 builds

After installing, enable Xime in Android's keyboard settings and select it as the current input method.

Based on [Xime](https://github.com/ximeiorg/Xime) and the [Rime](https://rime.im/) input engine.
